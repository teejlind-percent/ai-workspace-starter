# Critic bench

1. **Pick the panel.** Use the critics the user names. Otherwise propose three real readers of this piece who would disagree with each other (e.g., for a role-play: a small-business owner, a bank manager, a marketing director; for a flyer: a freshman who's never heard of the club, a parent, a teacher who has to approve it). Each one gets a name, a role, and what they care about most.
2. **Keep them independent.** If you can run subagents, give each critic only the draft and its persona, not this conversation, so they aren't swayed by what you already think. If you can't, write each critique before reading the others.
3. **Each critic returns:**
   - A score from 1 to 10, with one sentence on why
   - The single weakest sentence, quoted exactly
   - One tough question they'd ask
   - What they'd need to see to give it a 9
4. **Do not rewrite the draft.** The user fixes it. That's where judgment gets built.
5. **Sum up in three lines:** where the critics agree (fix first), where they disagree (the user's call), and the one change that would move every score.
6. Offer to run the bench again after the user revises.
