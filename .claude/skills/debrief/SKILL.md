# Debrief

1. Find the project folder and read its `brief.md`. Compare what was planned to what happened.
2. Ask, two at a time: What worked? What broke? What surprised you? What would you do differently? What should next year's version of you know?
3. Write `debrief.md` in plain, specific sentences. "The flyer was late" isn't a lesson. "Printing takes three school days, so order by Tuesday" is.
4. Propose which lessons belong in `memory/lessons.md`. Add them only after the user agrees.
5. If a format worked well, offer to save it to `playbooks/`.
